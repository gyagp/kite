# The Orbit Collection

Six bundled experiences showcase EmbeddingGemma 2 with NASA photographs, spoken
narration generated with Azure AI Speech, an authored photo film, multilingual
queries, and combined inputs.
Open **Embeddings → Multimodal examples** to preview or run them locally.

- `showcase/earth.jpg`, `spacewalk.jpg`, `launch.jpg`, `saturn.jpg`, `pluto.jpg`,
  and `horizon.jpg`: NASA imagery. Full credits, source links, IDs, and hashes are
  in `showcase/credits.json`. NASA does not endorse Kite.
- `showcase/orbital-film.mp4`: a 12-second, 960×540, 24-fps H.264 photo montage,
  with pan/zoom, transitions, and titles. It is not original motion footage.
- `showcase/mission-brief.wav`: Azure AI Speech narration using
  `en-US-AvaMultilingualNeural`, 24-kHz mono PCM. `showcase/speech.json` records
  the voice, region, transcript, generation time, and audio hash; no credentials.
  `showcase/audio.json` contains the duration and measured waveform; the transcript
  is included in `examples.json`.
- `showcase/*-cover.jpg` and `film-scene-*.jpg`: presentation assets derived from
  the credited photographs.
- `examples.json`: the six editable recipes. Labels are display metadata and do
  not become model input text. Similarity scores come from actual inference.

To regenerate with the existing Evo Python/media environment:

```powershell
& ../evo/.venv/Scripts/python.exe scripts/build-showcase.py --fetch-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-showcase-voice.ps1
& ../evo/.venv/Scripts/python.exe scripts/build-showcase.py
```

Run these commands from the Kite project root. The voice script uses `SPEECH_KEY`
if set; otherwise it retrieves a key through your signed-in Azure CLI for
`speech-tts-358ca1c3-jpe` in `rg-speech-tts`. It discovers the region from that
resource unless `SPEECH_REGION` is set. Keys remain in the generator process and
are never bundled with Kite. Use `-Voice` to select another Azure voice.

To update just the narration, run the voice script followed by
`scripts/build-showcase.py --audio-only`; this refreshes the waveform, duration,
transcript, and credits without rendering the film again. Generation sends the
demo transcript to Azure Speech. Bundled playback and model inference run offline
after model/runtime setup.

The original `shapes.png`, `tree.png`, `beeps.wav`, and `moving-circle.mp4` remain
as small synthetic fixtures generated by `scripts/build-embedding-demos.py`.
These demonstrations are not retrieval quality benchmarks. Video contributes
sampled visual frames; attach audio separately to include sound.
