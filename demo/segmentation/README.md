# SAM 3 video example

`bedroom.mp4` contains frames 0, 2, …, 46 of the SAM 2 project's bedroom example,
played at 12 fps. Source: https://github.com/facebookresearch/sam2/tree/main/notebooks/videos/bedroom
The example is a real video; Kite produces its overlays with SAM 3 at runtime.
